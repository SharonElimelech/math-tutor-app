# 📐 המורה שלי — אפליקציה לניהול שיעורים פרטיים

אפליקציית **PWA** לניהול שיעורים פרטיים: תלמידים, יומן, תזכורות ותשלומים בוואטסאפ וסיכום הכנסות. עובדת בדפדפן, מותקנת בטלפון כמו אפליקציה רגילה ועובדת גם בלי אינטרנט. הנתונים נשמרים במכשיר ומגובים מוצפנים לענן. השרת הוא Cloudflare Worker חינמי.

## יכולות

- **מסך "היום"** — השיעור הבא, שורת "לטיפול" (שיעורים לאישור, תזכורות, גבייה) והיומן במסך אחד.
- **תלמידים** — שם, הורה, טלפונים, מחיר לשיעור, פעולות מהירות (וואטסאפ, קביעת שיעור).
- **יומן** — תצוגות יום / 3 ימים / שבוע / חודש / רשימה, שיעורים קבועים, גרירת שיעורים, סטטוס תשלום על כל שיעור.
- **התראות push** — לפני שיעור, בבוקר ואחרי שיעור (תזכורת תשלום), גם כשהאפליקציה סגורה.
- **וואטסאפ** — תזכורת שיעור, בקשת תשלום וסיכום שבועי, עם תבניות הודעה שניתן לערוך. "שליחה לכולם" בלחיצה אחת.
- **שליחה אוטומטית** — קיצור הדרך TutorAuto באייפון רץ בשעות שנבחרו, מושך מהשרת את ההודעות שהגיע זמנן ושולח בוואטסאפ. כל הודעה נשלחת פעם אחת. בהגדרות רואים מתי הקיצור רץ לאחרונה ומה שלח.
- **גיבוי לענן** — כל שינוי מגובה אוטומטית, מוצפן במכשיר (AES-GCM). שחזור בהתקנה חדשה עם קוד שחזור. גם ייצוא ושחזור מקובץ.
- **הכנסות** — דוח חודשי (התקבל / ממתין) וגרף של 6 חודשים.

## הרצה במחשב

צריך שרת מקומי (בגלל ה-Service Worker):

```bash
npx serve -l 8000 .
```

בדיקות: `npm run check` (בדיקת תחביר + `node --test`).

השרת (`push-server/`): `npx wrangler dev --local` להרצה מקומית, `npx wrangler deploy` לפרסום. סכמת מסד הגיבוי: `push-server/schema.sql`.

## התקנה בטלפון

1. פותחים את כתובת האתר בספארי / כרום.
2. בתפריט הדפדפן בוחרים **"הוספה למסך הבית"**.
3. לשליחה אוטומטית: הגדרות ← וואטסאפ ← "הגדרה חד-פעמית באייפון".

## מבנה הקבצים

```
index.html          # מבנה, ניווט וכפתור פעולה צף
styles.css          # עיצוב RTL רספונסיבי, מצב כהה
app.js              # מסכים, יומן, מרכז התזכורות, וואטסאפ, גיבוי
src/                # מודולים: נתונים, יומן, תזכורות, push, אוטומציה, גיבוי מוצפן
tests/              # node --test
push-server/        # Cloudflare Worker: push, תור הוואטסאפ, גיבוי (KV + D1)
shortcuts/          # קיצורי הדרך לאייפון (TutorAuto, TutorSend)
service-worker.js   # עבודה בלי אינטרנט + התקנה
```
