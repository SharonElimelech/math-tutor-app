# 📐 המורה שלי — אפליקציה לניהול שיעורים פרטיים

אפליקציית **PWA** (Progressive Web App) לניהול שיעורים פרטיים: תלמידים, יומן, תזכורות תשלום בוואטסאפ וסיכום הכנסות. עובדת בדפדפן, ניתנת להתקנה בטלפון כמו אפליקציה רגילה, ועובדת גם בלי אינטרנט. כל הנתונים נשמרים מקומית במכשיר (localStorage) — אין שרת ואין עלויות.

## יכולות

- **ניהול תלמידים** — שם, שם הורה, טלפון, מחיר לשיעור.
- **יומן שיעורים** — קביעת שיעורים, סימון "בוצע", תצוגת שיעורים קרובים.
- **תזכורות בדפדפן** — התראה ~30 דקות לפני שיעור (כשהאפליקציה פתוחה ברקע).
- **תזכורות תשלום בוואטסאפ** — האפליקציה מכינה הודעה עם הסכום ופותחת את וואטסאפ עם ההודעה מוכנה; את רק לוחצת "שלח".
- **סיכום הכנסות** — דוח חודשי (התקבל / ממתין) + גרף 6 חודשים אחרונים.

## הרצה מהירה במחשב

מכיוון שיש Service Worker, צריך להריץ דרך שרת מקומי (לא לפתוח את הקובץ ישירות):

```bash
# בתיקיית הפרויקט:
python3 -m http.server 8000
# ואז לפתוח בדפדפן: http://localhost:8000
```

או עם Node:
```bash
npx serve .
```

## התקנה בטלפון

1. העלי את התיקייה לאחסון חינמי שתומך ב-HTTPS, למשל **Netlify** (גרירה של התיקייה ל-netlify.com/drop) או **GitHub Pages**.
2. פתחי את הכתובת בטלפון בכרום/ספארי.
3. בתפריט הדפדפן בחרי **"הוספה למסך הבית" / "Add to Home Screen"**.
4. האייקון יופיע במסך הבית ויפתח במסך מלא כמו אפליקציה.

## טכנולוגיות

HTML, CSS, Vanilla JavaScript, PWA (manifest + service worker), localStorage, Web Notifications API, Canvas (לגרף), WhatsApp Click-to-Chat API.

## מבנה הקבצים

```
index.html          # מבנה ותפריט ניווט
styles.css          # עיצוב RTL רספונסיבי
app.js              # כל הלוגיקה (נתונים, מסכים, וואטסאפ, גרף, תזכורות)
manifest.json       # הגדרות PWA
service-worker.js   # תמיכה offline + התקנה
icon-192/512.png    # אייקונים
```
